# Knowledge Base - база знаний rbxgen

Единое место для данных, правил и рецептов.

## Структура

- **models/** - данные о моделях (размеры, ориентация, Origin)
- **rules/** - правила сборки, размещения, соединений
- **recipes/** - рецепты моделей (LEGO-инструкции)

## Аналогия

Как нейросеть учится на данных - так rbxgen учится на моделях Kenney.

| Нейросеть | rbxgen |
|-----------|--------|
| Данные | knowledge/models/ |
| Правила | knowledge/rules/ |
| Инференс | knowledge/recipes/ |
| Результат | 3D-модель |

## Как использовать

1. Генератор читает recipe (JSON).
2. Находит модели в models/.
3. Применяет правила из rules/.
4. Собирает 3D-модель.
